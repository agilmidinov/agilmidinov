
# Привет, я Александр — Программист 1С

Перешёл в разработку осознанно: сочетаю навыки бизнес-анализа с технической реализацией. Мой опыт в управлении процессами (в т. ч. в финансовом секторе) помогает мне проектировать решения, которые закрывают реальные потребности пользователей, а не просто соответствуют ТЗ.

## Текущие проекты и результаты

### Конфигурация для салона красоты (Дипломный проект)
**Цель:** Автоматизация учёта услуг и товаров, формирование отчётности и печати документов.
**Что реализовано:**
*   **Учётная подсистема:** спроектированы механизмы оперативного и бухгалтерского учёта, включая проводки и контроль остатков.
*   **Автоматизация:** настроена загрузка прайс-листов из Excel, реализована внешняя печатная форма товарной накладной.
*   **Отчётность:** внедрены аналитические отчёты на базе Библиотеки стандартных подсистем (БСП).
*   **Интерфейс:** донастроен командный интерфейс для удобства пользователей.
**Стек:** 1С:Предприятие 8, БСП, СКД, Excel.

### Типовая конфигурация под бизнес-процесс (Учебный проект)
**Цель:** Отработка навыков работы с основными объектами платформы и оптимизация производительности.
**Что реализовано:**
*   **Архитектура данных:** разработаны справочники, документы, регистры накопления и механизмы проведения.
*   **Отчётность:** спроектирован отчёт по остаткам с использованием СКД.
*   **Оптимизация:** переработаны типовые запросы 1С для ускорения формирования отчётов на больших объёмах данных.
**Стек:** 1С:Предприятие 8, запросы 1С, СКД, регистры.
